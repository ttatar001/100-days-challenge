# Dane do przekazania agentowi

Na start prześlij opis lub zrzut ekranu przykładowego dania NTFY i podstawowy profil. Możesz wkładać pliki do tego folderu lub przekazywać informacje w rozmowie z Codexem. Agent ma uzupełniać projekt na podstawie rzeczywistych danych.

Potrzebne dane: data startu, wiek, wzrost, aktualna i docelowa masa, zdrowie i urazy istotne dla planu, doświadczenie treningowe, dostępny sprzęt, typowy tydzień pracy i snu, preferencje i wykluczenia jedzenia, szczegóły pakietu NTFY oraz wybrana częstotliwość pomiarów.

Przed planowaniem tygodnia przekaż: terminy i role na meczach, dojazd, proponowane treningi, dostępne godziny i posiłki już zamówione. Pamiętaj również o niedzieli.

Nie przekazuj hasła do Garmina w pliku lub rozmowie. Logowanie importera będzie wykonywane lokalnie.
